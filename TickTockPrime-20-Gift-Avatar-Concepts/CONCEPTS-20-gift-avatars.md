## Quick production notes (Tick Tock–style gifts)

1. **Keep the 3-beat ritual** somewhere in every animation: cue → pin → seal (even if stylized).  
2. **Always end on Orion Gold key / seal stamp** for brand recall.  
3. **No real token JSON, nonces, or secrets** in UI overlays — use stylized glyphs only.  
4. **Length:** 3–5s; Mythic can stretch to 5s with a final freeze for screenshot / share.  
5. **Audio:** soft argon “pressure” thumps + teal lock chime + gold seal click.
